Bu repository, 2026-2027 eğitim-öğretim yılında yürütülen **Web Teknolojileri** dersi kapsamında kullanılan örnek kodları ve uygulamaları içermektedir.

## Ders İçeriği

Ders kapsamında web teknolojilerinin temel yapıları uygulamalı olarak ele alınacaktır.

### 1. HTML

Web sayfalarının temel yapısının oluşturulması.

- HTML etiketleri
- Başlıklar ve metinler
- Listeler
- Linkler
- Görseller
- Tablolar
- Formlar
- Semantik HTML

### 2. CSS

Web sayfalarının görsel olarak biçimlendirilmesi.

- CSS kullanımı
- Renkler
- Yazı tipleri
- Margin ve Padding
- Border
- Box Model
- Display
- Position
- Flexbox
- Grid
- Responsive tasarım

### 3. Bootstrap

Hazır CSS bileşenleri kullanılarak responsive web arayüzleri oluşturulması.

- Bootstrap kurulumu
- Container ve Grid sistemi
- Responsive tasarım
- Butonlar
- Navbar
- Cards
- Forms
- Alerts
- Tables
- Modal
- Bootstrap bileşenleri

### 4. JavaScript

Web sayfalarına etkileşim ve dinamik özellikler kazandırılması.

- Değişkenler
- Veri tipleri
- Operatörler
- Koşullar
- Döngüler
- Fonksiyonlar
- Diziler
- Nesneler
- DOM
- Event işlemleri
- Form işlemleri
- Fetch API
